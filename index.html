01 THE BUILDING BLOCKS

What are operators?

An operator is a symbol that tells C what to do with values. We’re focusing on binary operators: each one acts on two operands.

A LITTLE EXPRESSION
aoperand +operator boperand
a + b → add the values
+

Operator

A symbol that performs an action. Here, + means “add”.

a

Operand

A value the operator works on. Here, a and b are the operands.

Why “binary”?

A binary operator needs two operands: one on each side. In a + b, those are a and b.

03 THE BIG PICTURE

One operator.
Two inputs.

A binary operator takes two values, called operands, performs an action, and produces a result.

8operand > 5operand → 1true

In C, 8 > 5 is true, so the result is 1.

THE OPERATOR FAMILIES5 QUICK EXAMPLES
01+   -   *   /   % Arithmetic Do maths with two numbers. 12 + 5 → 17
02<   >   ==   != Relational Compare values; get true (1) or false (0). 8 > 5 → true
03&&   || Logical Combine two true-or-false conditions. 1 && 0 → false
04=   +=   -= Assignment Store a value or update what is already stored. score += 2 → add 2
05&   |   ^   <<   >> Bitwise Work on the binary bits in two integers. 5 & 3 → 1
